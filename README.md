# jammer_app

A new Flutter project.

## Supabase setup

- Create the tables and storage bucket listed in [docs/supabase_schema.md](docs/supabase_schema.md).
- Copy [.env.example](.env.example) to `.env` and fill in `SUPABASE_URL` and `SUPABASE_ANON_KEY`.
- Run with `flutter run -d chrome`.
